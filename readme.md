# RingyoZumenMaker

QGISのポリゴン・ライン・オルソ画像から、森林整備事業向けの申請区域図、付帯作工物図、位置図を作成するプラグインです。複数の図面を一つのHTMLにまとめ、SHPと、手動編集・再作成に使うQGISプロジェクトも出力します。

[入力データのサンプル](sample/)／[QGISで図面を編集する方法](qgs_editing.md)

## 仕様・動作環境

北海道庁の[無人航空機を活用した森林整備事業の補助申請等の取扱いについて](https://www.pref.hokkaido.lg.jp/fs/1/3/1/2/9/9/9/8/_/%E7%84%A1%E4%BA%BA%E8%88%AA%E7%A9%BA%E6%A9%9F%E3%82%92%E6%B4%BB%E7%94%A8%E3%81%97%E3%81%9F%E6%A3%AE%E6%9E%97%E6%95%B4%E5%82%99%E4%BA%8B%E6%A5%AD%E3%81%AE%E8%A3%9C%E5%8A%A9%E7%94%B3%E8%AB%8B%E7%AD%89%E3%81%AE%E5%8F%96%E6%89%B1%E3%81%84%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6.pdf)に基づいて作成しています。

- QGIS 4.0以降
- Python 3.12以降（QGIS同梱環境）
- Pythonパッケージ `lxml`

## インストール

最新版の[Releases](../../releases/latest)からプラグインのZIPを取得し、QGISの「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」で読み込みます。

Gitを使う場合は、QGISのプラグインフォルダへクローンします。

```powershell
# Windows
cd $env:APPDATA\QGIS\QGIS4\profiles\default\python\plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

```bash
# Linux
cd ~/.local/share/QGIS/QGIS4/profiles/default/python/plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

## 最初に図面を作る

1. QGISへ施行地のポリゴン、除地、付帯作工物のライン、オルソ画像などを読み込みます。
2. 「基本情報」で製図情報、CRS、用紙サイズ、縮尺を設定します。
3. 「施行地」「除地」「その他」「付帯作工物」で使用するレイヤを指定します。
4. 「出力」で既存の出力フォルダを選び、「試算」で計算結果を確認します。
5. 「実行」を押し、出力された `index.html` をブラウザで開きます。

施行地の対象地物を一つの申請区域図へまとめます。付帯作工物は一地物につき一つの図面を作成します。例えば、施行地が3地物、付帯作工物が2地物なら、申請区域図1枚と付帯作工物図2枚を生成します。マルチラインも一地物として扱います。

申請区域図と付帯作工物図はそれぞれ省略できますが、少なくとも片方に対象地物が必要です。

## 基本情報タブ

### 座標系

CRSは、現場に合ったメートル単位の投影座標系を選びます。緯度経度のCRSは使用できません。入力レイヤは指定したCRSへ変換してから、面積・延長・基準点間距離を計算します。

### 説明

| 項目 | 用途 |
|---|---|
| 製図日 | HTMLの製図年月日と、地物属性の既定値。 |
| 製図事業者名 | HTMLの製図者氏名欄の上段。 |
| 製図者名 | HTMLの製図者氏名欄の下段と、地物属性の既定値。 |
| 林小班 | 申請区域図の名称、位置図の表題、出力ファイル名。空欄の場合、申請区域図名・位置図ファイル名には「全体」を使用。 |
| 森林所有者名 | HTMLの表題情報と、地物属性の既定値。 |
| 申請番号 | 全図面の表題欄とSHPの `申請No`。空欄でも実行できますが、確認のアラートを表示。 |

「施行地」「付帯作工物」の製図年月日・製図者名・森林所有者名を個別指定すると、その値を地物属性へ使用します。付帯作工物図の表題も個別値を使用します。申請区域図の表題は基本情報の値を使用します。

### 地図

| 項目 | 動作 |
|---|---|
| 出力形式 | A4またはA3。HTML図面は横向き。位置図も同じ用紙サイズになります。 |
| 縮尺 | HTML図面の地図縮尺。用紙サイズに合わせて地図枠を調整し、印刷時の縮尺を保ちます。 |
| 全体図に計算を表示 | 有効なら申請区域図に更新面積・除地・申請面積の計算式を表示。無効ならSHPと同じ小数点以下2桁の更新面積・申請面積（ha）だけを表示。 |
| 面積（m²）表示の小数桁数 | 計算式のm²表示を0〜9桁で四捨五入。初期値は0桁。内部計算値は丸めません。 |
| 面積（ha）表示の小数桁数 | 計算式の最終ha値を0〜9桁で切り捨て。初期値は2桁。SHPの保存桁数は別途固定です。 |
| 位置図の生成 | 全図面の区域・付帯作工物をまとめた位置図PDFを一つ生成。 |
| 位置図の向き | 縦または横。方位記号は右上、表題・縮尺・スケールバーの帯は右下に配置。 |
| 位置図の縮尺 | HTML図面とは別に指定する位置図PDFの縮尺。 |

オルソ画像を指定したHTML図面は、その画像の中心を地図枠の中心にします。指定縮尺で区域が枠外になる場合は出力ログへ案内を表示します。基準点が枠外になる場合はエラーです。全体を収めるには縮尺の分母を大きくしてください。

## レイヤ・式の指定

各タブの「フィルタ」は、選択したレイヤの地物をQGIS式で絞り込みます。空欄なら全地物が対象です。単に地図上で地物を選択しただけでは絞り込まれません。

```qgis
-- 選択中の地物だけを対象にする
is_selected()

-- 属性によって対象を絞る
"type" = '排水'
```

「地物名」「林小班枝番」も地物ごとに評価するQGIS式です。フィールドを使う場合は `"name"`、固定文字列を使う場合は `'排水1'` のように指定します。地物名が空欄またはNULLなら名称ラベルを表示せず、計算式にも名前を付けません。

入力欄の右にある上書きボタンでは、左の入力値をフィールドや式で置き換えられます。先にそのタブのレイヤを選び、ボタンからフィールドまたは式を指定してください。有効にすると左の固定値入力は操作できなくなります。無効にすると固定値へ戻ります。

```qgis
-- 幅を属性から取得する
"width_m"

-- 製図年月日を式で指定する
to_date('2026-10-05')
```

式はそのタブで選んだレイヤの各地物を使って評価します。林班・小班は0以上の整数、幅は小数点以下2桁で0.01m以上、製図年月日は有効な日付で指定します。

## 施行地タブ

「ポリゴンレイヤ」「フィルタ」「地物名」で対象区域を指定します。選んだすべての対象地物を一つの申請区域図・一つのSHPにまとめ、各地物の属性は個別に保存します。マルチポリゴンは元の一地物として保持します。

| 属性入力 | 指定方法 |
|---|---|
| 振興局 | 一覧から選択。 |
| 市町村 | 固定文字列または上書きボタンの式。 |
| 林班・小班 | 固定整数または上書きボタンの式。空欄も可。 |
| 林小班枝番 | QGIS式。空欄も可。 |
| 事業コード | 固定文字列または上書きボタンの式。先頭の0が必要なら文字列で指定。 |
| 製図年月日・製図者名・森林所有者名 | 個別値または上書きボタンの式。空欄なら基本情報を使用。 |

製図年月日・製図者名・森林所有者名は、個別に編集するまで基本情報の変更にも連動します。市町村・林班・小班・事業コードなどが空欄の場合は確認のアラートを表示しますが、処理は続行します。

## 除地タブ

除地ポリゴンと除地ラインを、それぞれレイヤ・フィルタ・地物名で指定します。使用しない方はレイヤを空欄にできます。除地は申請区域図の施行地へ適用します。

除地ラインの「幅」は全幅です。例えば幅2mなら、ラインの左右へ1mずつバッファを作ります。端と曲がり角は丸めません。幅は固定値または上書きボタンの式で指定できます。

計算は次の順序で行います。

1. 除地ポリゴンとラインのバッファを統合し、除地同士の重なりを一度だけ扱います。
2. 各施行地ポリゴンの内側にある除地部分を取り出します。区域外の部分は差し引きません。
3. 取り出した除地を連続したポリゴン部分ごとに判定し、「最小除地面積」以上の部分だけを差し引きます。

「最小除地面積」の単位はa（1a = 100m²）、初期値は1aです。ポリゴン由来・ライン由来の両方に適用します。閾値未満の部分は施行地へ残り、試算ログへ対象外として表示されます。

| 計算欄 | 意味 |
|---|---|
| 更新面積 | 除去前の施行地ポリゴン面積の合計。 |
| 除地 | 採用した除地部分の面積の合計。 |
| 申請面積 | 更新面積から除地を差し引いた面積。 |

例えば施行地が10,000m²と10,000m²、採用した除地が200m²と150m²なら、更新面積20,000m²、除地350m²、申請面積19,650m²、最終表示は1.96haです。

除地ラインの項目は `200m²（排水1・延長100m × 幅2m）` のように表示します。面積は実際の形状から計算し、式内の延長はm単位で切り捨てます。区域との交差や除地同士の重なりによって、表示した「延長×幅」と面積が一致しない場合があります。

計算式はKaTeXで表示します。表示の丸めによって左右の値が一致しない箇所は `≃`、一致する箇所は `=` で結びます。除地の各項目と合計は右寄せで、長い式は折り返します。最終ha値は赤字で表示します。

施行地の面積は地物ごとに合計します。施行地ポリゴン同士が重なる場合は、その重なりも各地物に含まれるため、入力区域の重複を確認してください。

## その他タブ

### 基準点

「基準点ポイントレイヤ」と「フィルタ」で2点を指定します。フィルタが空欄なら全地物が対象です。マルチポイントは中の点数で数えます。

指定した2点を、HTML図面の地図上に直径2mmの赤点で表示します。地図右上には基準点の凡例を表示し、GPKGにも基準点のポイントレイヤを保存します。

2点以外の場合、または点間距離が「最小基準点距離」未満の場合はエラーです。初期値は20m。距離の上書き式を使う場合は、選ばれた地物の値のうち最大値を基準にします。基準点レイヤを空欄にすると点と凡例を省略します。

### オルソ画像

「オルソ画像レイヤ」でHTML図面の背景を選びます。コピーも必要な場合は、「出力」タブの「リネームしてコピーするオルソ画像」へ元ファイルを指定します。この二つの指定は別です。

位置図の背景はQGISの地図画面で表示している他のレイヤから取得します。入力に指定したレイヤ、「その他」で選んだオルソ、コピー対象の画像、スクラッチレイヤは位置図の背景に含めません。位置図では除地を除いた申請区域を赤、付帯作工物を青で重ね、付帯作工物を前面に表示します。区域・付帯作工物の名称ラベルは表示せず、付帯作工物の線はHTML図面の半分の太さです。

## 付帯作工物タブ

「ラインレイヤ」「フィルタ」「幅」「地物名」を指定します。属性入力は施行地と同じ方法です。対象の一地物につき一つの図面とSHPを作成し、マルチラインも一つの図面にまとめます。地物名が空欄なら、図面名には「地物1」などを使用します。

付帯作工物は、HTML・位置図・SHP・GPKGのすべてでラインとして扱います。幅は属性・図面の表示用で、ポリゴン化や除地の差し引きは行いません。

計算欄には地物名、幅、延長を表示します。幅は小数点以下2桁、延長はm単位で切り捨てた整数です。延長は申請面積の最終ha値と同じ大きさの赤字で表示します。例えば幅2m・延長120.9mなら `2.00m`、`120m` と表示します。

## 出力タブ

### 試算・実行

出力先には存在するフォルダを指定してください。「試算」も出力先の指定が必要です。

- **試算**：各図面の更新面積・除地・申請面積、または付帯作工物の延長・幅、基準点間距離などを出力欄に表示します。成果ファイルは生成しません。
- **実行**：選択した出力方法でファイルを生成します。

| 出力方法 | 用途 |
|---|---|
| 再計算して図面・データを更新 | 入力レイヤから計算し、HTML・位置図PDF・SHP・QGZ・GPKGを更新します。初回作成にも使います。 |
| 現在の成果から図面・SHPを出力 | 生成したQGZを開き、現在のレイアウトと最終出力レイヤからHTML・位置図PDF・SHPを出力します。QGZ・GPKGは変更しません。 |

「現在の成果から図面・SHPを出力」では面積・延長を再計算しません。形状変更に合わせて計算値も更新する場合は「再計算して図面・データを更新」を選びます。

### 設定の保存・読み込み

「設定を保存」は次の3通りです。設定ファイルは再計算による出力時に保存します。

- **しない**：設定ファイルを作成しません。
- **出力フォルダに自動生成**：`input.config` を保存します。
- **ファイルを指定して生成**：「設定保存ファイル」へ保存します。

画面下部の「設定読み込み」から `.config` を選ぶと入力設定を復元します。参照レイヤが見つからない場合は通知し、その欄を空欄にします。設定ファイル自体はレイヤの地物データを保存しません。

生成した `図面編集・再作成.qgz` にも再作成用設定を埋め込みます。このQGZを開くと、保存されたGPKGの入力レイヤを使う設定が復元されます。自動では生成しません。

前回のフォーム入力は自動保存しません。入力設定を復元するには設定ファイルを読み込むか、生成したQGZを開いてください。

### オルソのコピー

「リネームしてコピーするオルソ画像」へ指定すると、`オルソ/` に一つコピーします。ワールドファイルなどの地理参照ファイルも一緒にコピーします。対応形式はTIF、TIFF、JPG、JPEG、PNG、JP2、ECW、IMGです。

「その他」で選んだオルソと同じファイルをコピーした場合、生成QGZはコピー先を参照します。コピーを指定しなければ元画像を参照します。

### バックアップ

「生成ファイルのバックアップ」を有効にすると、前回の生成物を `backup/日時/` へ退避してから更新します。以前の図面名で出力したファイルや、今回省略する図面の生成物も対象です。

再計算で無効の場合は前回の生成物を更新し、今回使わない生成ファイルを削除します。自分で出力フォルダへ追加したファイルは移動・削除しません。生成先と同名の未登録ファイルがある場合はエラーになるので、別名や別フォルダへ移してください。

生成QGZを開いたまま同じ出力フォルダへ再計算する場合、バックアップには現在の未保存のレイアウト・スタイル変更も反映します。地物編集が未保存なら、保存・取り消し・中止を選ぶ確認が出ます。「現在の成果から図面・SHPを出力」ではQGZ・GPKGをバックアップ対象に含めません。

## 出力ファイル

```text
出力フォルダ/
├── index.html
├── input.config                    # 自動保存を指定した場合
├── qgz/
│   ├── ringyo_zumen.gpkg
│   └── 図面編集・再作成.qgz
├── 申請区域 - 図面名/
│   └── shp/
├── 付帯作工物 - 地物名/             # 地物ごとに生成
│   └── shp/
├── 位置図/                         # 生成を指定した場合
│   └── 林小班名 - 位置図.pdf
├── オルソ/                         # コピーを指定した場合
├── backup/
│   └── 日時/
└── asset/
    ├── drawing_1_map.png
    ├── drawing_2_map.png
    ├── QGISで図面を編集する方法.md
    └── スタイルシート・方位記号・数式表示用ファイル
```

図面名や生成数は入力設定によって変わります。SHPのフォルダには `.shp`・`.dbf`・`.shx`・`.prj` などの関連ファイルと、QGIS用の `.qml` スタイルを保存します。提出用ZIPは生成しません。

出力フォルダを移動するときはフォルダ全体を移動し、内部の配置を保ってください。生成QGZからGPKG・コピーしたオルソへの参照は相対パスです。位置図の背景やコピーしなかった画像は元データを参照するため、別PCでもそのデータへアクセスできる必要があります。

### SHPの属性

全図面に次の属性を保存します。

| フィールド | 内容 |
|---|---|
| 振興局・市町村 | 各タブで指定した名称。 |
| 林班・小班・枝番 | 各タブで指定した林小班情報。 |
| 製図日・製図者・所有者 | 各地物の指定値、または基本情報の値。 |
| 事業 | 事業コード。 |
| 申請No | 基本情報の申請番号。 |

図面の種類によって、次の属性が加わります。

| 図面 | フィールド | 内容 |
|---|---|---|
| 申請区域図 | 面積ha | 除地を差し引いた各地物の面積。haへ換算し、小数点以下5桁で切り捨て。 |
| 申請区域図 | 更新ha | 図面全体の除去前面積。haへ換算し、小数点以下2桁で切り捨て。 |
| 申請区域図 | 申請ha | 図面全体の申請面積。haへ換算し、小数点以下2桁で切り捨て。 |
| 付帯作工物図 | 幅m | 全幅。小数点以下2桁。 |
| 付帯作工物図 | 延長m | 延長をm単位で切り捨てた整数。 |

`更新ha`・`申請ha` は同じ申請区域図の各地物へ同じ合計値を保存します。付帯作工物のSHPには面積・更新面積・申請合計面積の属性を保存しません。

### QGZとGPKG

`図面編集・再作成.qgz` に全図面と位置図の地図レイアウト、図面ごとの地図テーマ、スタイル、ラベル位置、再作成用設定をまとめます。HTMLの表題・計算欄はプラグインが作成し、QGISの各図面レイアウトは地図部分を編集するために使います。

GPKGには指定した入力ベクタレイヤの全地物・全属性と、最終出力の区域・付帯作工物・基準点を保存します。入力がスクラッチレイヤでも保存され、フィルタで対象外の入力地物も残ります。空レイヤと計算途中のバッファなどは保存しません。同じデータは共用し、HTML図面と位置図の見た目の違いはQGZ内のスタイルと地図テーマで管理します。

## 図面の確認・印刷・編集

`index.html` をブラウザで開き、上部の選択欄または前後のボタンで図面を切り替えます。地図左上の「地図を表示」で、その図面の地図欄を表示・非表示にできます。操作ボタンやチェックボックスは印刷には出ません。

通常は表示中の図面を印刷します。「全図面を印刷」を有効にするとすべて印刷します。印刷設定は指定したA4/A3・横向きに合わせ、倍率100%、余白なし、ブラウザのヘッダー・フッターなしで出力すると、図面の縮尺を保てます。

地図の調整には `qgz/図面編集・再作成.qgz` を開き、地図テーマで対象図面を選びます。地図画面で別のテーマを選んでも、レイアウトの縮尺・表示位置・向きは変わりません。スタイル変更をレイアウトへ反映するには対象テーマを更新します。

同じ生成QGZから再計算すると、同じ図面の手動編集・スタイル・ラベル位置を引き継ぎます。詳しい操作は[編集手順](qgs_editing.md)、または出力先の `asset/QGISで図面を編集する方法.md` を参照してください。

## エラーになる入力

- 施行地と付帯作工物の両方に対象地物がない。
- 無効なレイヤ、CRSのない入力、メートル単位ではない出力CRS。
- 空の形状、自己交差・ねじれなどの不正なポリゴン。
- 解釈できない式、数値・日付の条件を満たさない上書き値。
- 幅が0.01m未満、基準点が2点以外、点間距離不足、基準点が地図枠の外。
- 出力先が存在しない、コピー対象の画像が見つからない、指定した設定保存先が不正。

地物名と林小班枝番は空欄でも使用できます。市町村・林班・小班・事業コード・申請番号などの空欄は、エラーではなく確認のアラートになります。
