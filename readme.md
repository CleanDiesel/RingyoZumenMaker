# RingyoZumenMaker

QGISのポリゴン・ライン・オルソ画像から、森林整備事業向けの申請区域図、付帯作工物図、位置図、シェープファイルを作成するプラグインです。

[入力データのサンプル](sample/)／[図面の編集手順](qgs_editing.md)

## 動作環境

北海道庁の[無人航空機を活用した森林整備事業の補助申請等の取扱いについて](https://www.pref.hokkaido.lg.jp/fs/1/3/1/2/9/9/9/8/_/%E7%84%A1%E4%BA%BA%E8%88%AA%E7%A9%BA%E6%A9%9F%E3%82%92%E6%B4%BB%E7%94%A8%E3%81%97%E3%81%9F%E6%A3%AE%E6%9E%97%E6%95%B4%E5%82%99%E4%BA%8B%E6%A5%AD%E3%81%AE%E8%A3%9C%E5%8A%A9%E7%94%B3%E8%AB%8B%E7%AD%89%E3%81%AE%E5%8F%96%E6%89%B1%E3%81%84%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6.pdf)に基づいて作成しています。

- QGIS 4.0以降
- Pythonパッケージ `lxml`（通常は追加不要）

## インストール

[最新版のZIP](../../releases/latest)を取得し、QGISの「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」で読み込みます。

Gitを使う場合は、プラグインフォルダへクローンします。以下のパスは例です。インストール先やプラグインフォルダは環境・バージョン・プロファイルによって異なるため、実際のパスに置き換えてください。

```powershell
# Windows
cd $env:APPDATA\QGIS\QGIS4\profiles\default\python\plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

```bash
# Linux
cd ~/.local/share/QGIS/QGIS4/profiles/default/python/plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

## 図面を作る

1. 使用するポリゴン・ライン・画像をQGISへ読み込みます。
2. 「基本情報」でCRS、用紙サイズ、縮尺を設定し、必要なら基準点・オルソ画像を指定します。
3. 「施行地」「除地」「付帯作工物」でレイヤを選び、対象地物と属性を指定します。
4. 「出力」で既存の出力フォルダとQGZの作成有無を選び、「試算」で結果を確認します。
5. 「実行」を押し、出力された `index.html` をブラウザで開きます。

施行地は全対象を一つの申請区域図にまとめます。付帯作工物は一地物につき一つの図面を作成します。施行地・付帯作工物のどちらか一方だけでも作成できます。マルチポリゴン・マルチラインは一地物として扱います。

## 基本情報

### 座標系・地図・位置図

CRSは現場に合ったメートル単位の投影座標系を選びます。推奨はJGD2011またはJGD2000の平面直角座標系です。系番号は国土地理院の[区域一覧](https://vldb.gsi.go.jp/sokuchi/surveycalc/surveycalc/jpc/jpc.htm)で確認してください。

| 項目 | 設定内容 |
|---|---|
| 図面の用紙サイズ・縮尺 | 申請区域図・付帯作工物図はA4またはA3、横向き。 |
| 全体図に計算を表示 | 有効なら面積の計算式、無効なら更新面積・申請面積（ha）のみ表示。 |
| 面積表示の小数桁数 | m²は四捨五入（初期値0桁）、haは切り捨て（初期値2桁）。 |
| 位置図の生成 | 全対象をまとめた位置図PDFを作成。用紙サイズ・向き・縮尺は図面と別に指定。 |

区域や基準点が地図枠に収まらない場合は、縮尺の分母を大きくしてください。

### 基準点・オルソ画像

基準点はポイントレイヤから2点を指定します。図面には直径2mmの赤点で表示します。「最小基準点距離」の初期値は20mです。基準点を使わない場合はレイヤを空欄にします。

「オルソ画像レイヤ」は図面の背景です。出力フォルダに画像のコピーが必要な場合は、「出力」の「リネームしてコピーするオルソ画像」にも元ファイルを指定します。

位置図はQGISの地図画面にある他のレイヤを背景に使い、申請区域を赤、付帯作工物を青で表示します。入力に指定したレイヤ・オルソ・スクラッチレイヤは背景に含めません。

## レイヤ・属性の指定

「フィルタ」で対象地物を絞り込みます。空欄なら全地物が対象です。地図上の選択を使う場合は `is_selected()` を指定します。

```qgis
-- 選択中の地物だけ
is_selected()

-- 属性で絞り込む
"type" = '排水'
```

「地物名」「林小班枝番」はQGIS式で指定します。フィールドは `"name"`、固定文字列は `'排水1'` のように記述します。

各項目の右の上書きボタンから、固定値をフィールド・式に置き換えられます。式はそのタブの対象地物ごとに評価します。上書きを解除すると固定値に戻ります。

```qgis
-- 幅を属性から取得
"width_m"

-- 製図年月日を指定
to_date('2026-10-05')
```

林班・小班は0以上の整数、幅は0.01m以上、製図年月日は有効な日付を指定してください。名称や市町村・林小班・事業コード・申請番号などは空欄でも使用できます。

### 施行地

ポリゴンレイヤを指定し、「属性」に振興局・市町村・林班・小班・林小班枝番・事業コード・製図年月日・製図事業者名・製図者名・森林所有者名・申請番号を入力します。

申請区域図には、対象の施行地すべての製図年月日・製図事業者名・製図者名・森林所有者名・申請番号を、重複を除いて表示します。林班・小班も「12林班60小班、12林班61小班」のように全組み合わせを表示します。

### 除地

除地ポリゴン・除地ラインを指定します。ラインの「幅」は全幅です。幅2mなら左右へ1mずつ広げ、施行地と重なる部分を差し引きます。除地同士の重なりは二重に差し引きません。

「最小除地面積」はa単位（1a＝100m²）、初期値は1aです。連続した除地部分ごとに判定し、指定値未満の部分は差し引きません。

| 計算欄 | 内容 |
|---|---|
| 更新面積 | 除地を差し引く前の施行地面積。 |
| 除地 | 差し引く面積。 |
| 申請面積 | 更新面積 − 除地。 |

施行地同士が重なる場合は各地物の面積に含まれるため、入力区域の重複を確認してください。

### 付帯作工物

ラインレイヤ・幅・地物名を指定し、「属性」に振興局・市町村・林班・小班・林小班枝番・事業コード・製図年月日・製図事業者名・製図者名・森林所有者名・申請番号を入力します。幅は表示用で、施行地からの差し引きには使いません。図面には幅と延長を表示し、延長はm単位で切り捨てます。

付帯作工物図はその地物の入力値だけを使います。施行地の情報を使うのは、以下の継承を指定した項目だけです。

施行地と同じ値を使う項目は、上書きボタンの「施行地の値を継承」を選びます。もう一度選ぶと個別入力へ戻ります。空欄にするだけでは継承しません。

継承元は施行地の最初の対象地物です。施行地に対象がない場合は固定入力値を使います。

図面の名称例は「12林班60小班（枝番1） 排水1」です。地物名が空欄なら「地物1」などを使います。

## 出力

「試算」は計算結果の確認だけで、ファイルを作成しません。「実行」は入力から再計算して図面・シェープファイルを出力します。

| QGZの作成 | 動作 |
|---|---|
| 作成する（QGZ・GPKG） | 編集・再作成用のQGZとデータを保存するGPKGも作成・更新。 |
| 作成しない | 図面・シェープファイルを出力。既存のQGZ・GPKGは変更せず残す。 |

更新先は指定した出力フォルダです。QGZで手動調整した図面を引き継ぐ場合は、そのQGZを開いて「作成する」を選んでください。「作成しない」では現在の入力設定から図面を作り直します。

### 設定の保存・読み込み

「設定を保存」で、保存しない・出力フォルダに `input.config` を保存・保存先を指定、のいずれかを選びます。設定ファイルは「実行」時に保存します。

「設定読み込み」から `.config` を開くと入力設定を復元できます。生成したQGZを開いても設定を復元できます。設定は現在の形式のみ対応します。

### オルソのコピー

指定した画像と地理参照ファイルを `オルソ/` へコピーします。ファイル名は対象の林班・小班をまとめ、例えば `12林班60・61小班_13林班2小班 - オルソ.tif` になります。すべて未入力なら `オルソ.tif` です。

対応形式はTIF・TIFF・JPG・JPEG・PNG・JP2・ECW・IMG。拡張子は元画像に合わせます。

### バックアップ

有効にすると、出力フォルダ直下の `index.html`・`input.config` と、`asset`・`qgz`・`位置図`・`オルソ`・`申請区域 - 全体`・`付帯作工物` フォルダ内のファイルを `backup/日時/` へ退避します。生成履歴の有無にかかわらず、対象フォルダ内に手動で追加したファイルも含みます。

設定ファイルは直下の `input.config` だけが対象です。それ以外の `.config`、対象外のファイル・フォルダ、過去の `backup` は変更しません。

無効の場合は対象ファイルを上書きし、今回不要な対象ファイルを削除します。「QGZの作成」が「作成しない」の場合、既存のQGZ・GPKGなどのプロジェクトファイルは対象外です。使用中のコピー済みオルソ画像もそのまま残します。

## 出力ファイル

| ファイル・フォルダ | 用途 |
|---|---|
| `index.html` | ブラウザで表示・印刷する図面。 |
| `申請区域 - 全体/shp/` | 申請区域のシェープファイル。 |
| `付帯作工物/付帯作工物 - 地物名/shp/` | 地物ごとのシェープファイル。 |
| `位置図/位置図.pdf` | 位置図の生成を指定した場合。 |
| `オルソ/` | コピーを指定した画像。 |
| `qgz/林班小班.qgz` | オルソと同じ林班・小班の組み合わせで命名（例：`12林班60・61小班.qgz`）。未入力の場合は `未指定.qgz`。 |
| `qgz/ringyo_zumen.gpkg` | 入力・成果データ。QGZと一緒に保存。 |
| `input.config` | 設定の自動生成を指定した場合。 |
| `backup/` | 出力対象のファイルのバックアップ。 |
| `asset/` | 図面表示に必要な画像など。 |

移動する場合は出力フォルダ全体を移動してください。

### シェープファイルの属性

各タブで指定した振興局・市町村・林班・小班・枝番・製図日・製図者・所有者・事業コード・申請番号を保存します。

| 図面 | 追加する属性 |
|---|---|
| 申請区域図 | `面積ha`：各地物の申請面積（小数点以下5桁で切り捨て）。`更新ha`・`申請ha`：図面全体の面積（2桁で切り捨て）。 |
| 付帯作工物図 | `幅m`：小数点以下2桁。`延長m`：整数。 |

## 図面の確認・印刷・編集

`index.html` をブラウザで開き、上部の選択欄で図面を切り替えます。「全図面を印刷」でまとめて印刷できます。

印刷は指定したA4/A3・横向き、倍率100%、余白なし、ブラウザのヘッダー・フッターなしに設定してください。

地図を調整する場合は `qgz/林班小班.qgz` を開きます。操作は[図面の編集手順](qgs_editing.md)を参照してください。
