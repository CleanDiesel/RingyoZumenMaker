# RingyoZumenMaker

QGIS上のポイントレイヤから、林業向けの実測図、位置図を作成するプラグインです。地図画像、座標表、測量情報などをまとめたHTML図面を出力します。

[図面のサンプルはこちら](sample/)。
## 仕様

北海道庁の[造林事業に係る造林実測図の作成方法](https://www.pref.hokkaido.lg.jp/fs/1/3/1/2/9/9/9/9/_/%E9%80%A0%E6%9E%97%E4%BA%8B%E6%A5%AD%E3%81%AB%E4%BF%82%E3%82%8B%E9%80%A0%E6%9E%97%E5%AE%9F%E6%B8%AC%E5%9B%B3%E3%81%AE%E4%BD%9C%E6%88%90%E6%96%B9%E6%B3%95.pdf)に基づいて作成しています。

## 動作環境

- QGIS 4.0以降
- Python 3.12以降（QGIS同梱環境）
- Pythonパッケージ `lxml`

動作確認環境: QGIS 4.0.1 Norrköping

## 主な機能

- 周囲を複数登録し、周囲ポイントから施工地ごとの周囲線・面積・外周延長を計算
- 排水・林内路網を複数登録し、線形と延長を計算
- 排水・林内路網を除地として扱い、除地延長・除地面積・施工面積を計算
- 測点名をQGIS式で指定
- QGIS式による対象ポイントの絞り込みと結合順の指定
- 周囲図、排水・林内路網図、全体図を含むHTML図面を生成
- 位置図PDFを生成
- 作成した点・線レイヤをGeoPackageとして保存
- 試算機能で面積等の計算結果を事前確認

## インストール

### gitを使用する場合

1. プラグインフォルダ内で`git clone`します。

例：

```powershell
# Windows
cd $env:APPDATA\QGIS\QGIS4\profiles\default\python\plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

```bash
# Linux
cd ~/.local/share/QGIS/QGIS4/profiles/default/python/plugins
git clone https://github.com/CleanDiesel/RingyoZumenMaker.git
```

### zipからインストールする場合

1. [Releases](../../releases/latest)から最新版のzipをダウンロードします。
2. QGISを起動します。
3. 「プラグイン」タブの「プラグインの管理とインストール」を開きます。
4. 「ZIPからインストール」でダウンロードした`RingyoZumenMaker-(version).zip`を読み込みます。

## 使用方法

### 1. 基本情報

「基本情報」タブでは、図面の表題欄、XY座標表、地図、位置図、除地計算に共通して使う値を設定します。

#### 説明

| 項目 | 図面への反映 |
|---|---|
| 測量日 | HTML図面の「実測年月日」に表示します。 |
| 測量事業者名 | HTML図面の「実測者氏名」欄の上段に表示します。 |
| 測量者名 | HTML図面の「実測者氏名」欄の下段に表示します。 |
| 製図日 | HTML図面の「製図年月日」に表示します。 |
| 製図事業者名 | HTML図面の「製図者氏名」欄の上段に表示します。空欄の場合は測量事業者名を使用します。 |
| 製図者名 | HTML図面の「製図者氏名」欄の下段に表示します。空欄の場合は測量者名を使用します。 |
| 林小班 | HTML図面と位置図の表題情報に表示します。。 |
| 山林所有者名 | HTML図面と位置図の表題情報に表示します。 |

これらの文字項目は空欄でも実行できます。ただし、林小班を空欄にして位置図を生成すると、PDFのファイル名には「名称未設定」が使用されます。

#### 表

| 項目 | 動作 |
|---|---|
| 小数点以下座標表示桁数 | すべてのXY座標表に表示するX・Y座標の小数桁数を0〜9桁で指定します。初期値は5桁です。指定桁より下は四捨五入せず切り捨てます。 |
| 測点並べ替え | 「しない」では元の順序を保ちます。「昇順」「降順」では、周囲図・排水図・全体図のXY座標表を測点名で並べ替えてから24点ごとに分割します。例えば `No.2` は `No.10` より前に並びます。 |

#### 地図

| 項目 | 動作 |
|---|---|
| 縮尺 | 周囲図、排水・林内路網図、全体図、位置図の地図縮尺に使用します。|
| 排水・林内路網の除地計算を表示 | 有効にすると、HTML図面に除地面積、施工面積の計算欄を表示します。各排水項目の「除地として扱う」の設定と組み合わせて使用します。 |
| 排水・林内路網等種別 | 図面の名称と除地計算の項目名に使用します。初期値は「排水溝」で、作業道など別の種別に変更できます。 |
| 位置図の生成 | 有効にすると位置図PDFを生成します。生成した周囲線と排水・林内路網線を描画し、背景には対象の入力ポイントレイヤを除く現在のQGISキャンバスの可視レイヤを使用します。 |
| 位置図周囲色 | 位置図に描画する周囲線の色を指定します。空欄の場合は同梱スタイルの既定色を使用します。 |
| 位置図排水・林内路網色 | 位置図に描画する排水・林内路網線の色を指定します。空欄の場合は同梱スタイルの既定色を使用します。 |
| 最小除地面積 | 除地面積として集計する最小値をa（アール）で指定します（1a = 100m²）。排水の幅×延長がこの値未満の場合、その項目の除地延長と除地面積は0として扱います。初期値は1aです。 |
| QGZのバックアップ作成 | 有効にすると、既存の `qgz` フォルダを作成日時付きの `qgz-YYYYMMDD-HHMMSS` へ変更してから、新しい編集用QGZ一式を生成します。|

### 2. 座標系

「座標系」タブで出力図面のCRSを指定します。

長さと面積は、指定したCRSへ再投影したレイヤから計算します。緯度経度などの地理座標系やメートル単位ではないCRSは使用できません。現場の地域に合った平面直角座標系などを指定してください。

推奨CRS：JGD2011 / Japan Plane Rectangular CS I\~XIX または JGD 2024 Japan Zone 1\~19

### 3. 周囲実測図

周囲実測図を出力する場合は「周囲の図面を出力」を有効にします。「周囲を追加」で入力欄を増やし、施工地ごとに名前、ポイントレイヤと以下のQGIS式を指定します。名前は空欄でも構いません。空欄の場合、全体図には名称ラベルを表示しません。

- 対象を絞り込むQGIS式（空欄の場合はレイヤ全体）

```qgis
# 選択中のポイントだけを対象にする
is_selected()

# 属性 field に「周囲」が入っているポイントだけを対象にする
"type" = '周囲'
```

- 測点名のQGIS式

```qgis
# 測点名を name フィールドから表示する
"name"

# 測点名を「No.1」「No.2」のように表示する
'No.' || "number"
```

- ポイントの結合順を決めるQGIS式

```qgis
# number フィールドの昇順でポイントを結合する
"number"

# name フィールドを自然順で結合する
"name"
```

### 4. 排水・林内路網実測図

排水・林内路網実測図を出力する場合は「排水・林内路網の図面を出力」を有効にします。「排水を追加」で入力欄を増やし、それぞれに名前等を指定します。名前は空欄でも構いません。空欄の場合、図面上には名称を表示しません。

各排水・林内路網は「除地として扱う」を選択できます。除地として扱う場合、除地面積を計算し、周囲面積から除地面積を引いた面積をHTML図面の除地計算欄に表示します。（「排水・林内路網の除地計算を表示」をオンにしてください）各項目の除地面積が「最小除地面積」未満の場合は除地延長・除地面積に含めず、除地計算の前に設定値に応じた「○m²未満は0m²」と表示します。除地計算式は、プラグインに同梱したKaTeXでLaTeX表示します。

### 5. 出力

「出力」タブで既存の出力フォルダを指定します。「設定を保存」では次の保存方法を選べます。設定ファイルは図面の出力が完了したときに作成され、同名ファイルがある場合は上書きします。

- 「しない」: 設定ファイルを作成しません。
- 「出力フォルダに自動生成」: 出力フォルダへ `input.config` を作成します。
- 「ファイルを指定して生成」: 「設定保存ファイル」で指定した `.config` ファイルへ保存します。

- 「試算」: 面積、周長等の計算結果を確認します。ファイルは生成しません。
- 「実行」: ファイルを生成します。

画面下部の「設定読み込み」を押すとファイル選択ダイアログが開きます。保存済みの `.config` ファイルを選ぶと、入力欄の設定を画面へ反映します。

## 出力ファイル

指定フォルダへ次のファイルを生成します。

```text
出力フォルダ/
├── index.html
├── qgz/
│   ├── ringyo_zumen.gpkg
│   ├── shui_1.qgz
│   ├── shui_2.qgz
│   ├── haisui_1.qgz
│   ├── haisui_2.qgz
│   ├── mix.qgz
│   ├── location.qgz
│   ├── houi2.svg
│   └── 操作説明.md
├── 林小班名 - 位置図.pdf
└── asset/
    ├── index.css
    ├── houi.svg
    ├── shui_1_map.png
    ├── shui_2_map.png
    ├── haisui_1_map.png
    ├── haisui_2_map.png
    └── mix_map.png
```

選択した製図種別、位置図の生成設定、排水・林内路網の登録数によって、生成されるPNGファイルやPDFは異なります。`index.html`をWebブラウザで開くと図面を確認できます。
印刷する場合ブラウザの印刷機能を使用します。ページ上のセレクトボックス、ボタンなどは印刷時に非表示になります。

ラベルがうまく配置されない場合等、地図に不満がある場合は生成されたQGZファイルを編集し変更した地図画像、位置図を作成できます。手順は生成される `qgz/操作説明.md`、または[編集手順](qgs_editing.md)を参照してください。

## 注意

- 同じ出力フォルダを使用すると、同名のHTML、画像、アセットが上書きされます。
- `qgz` 内の同名QGZ・GeoPackageも上書きされます。「QGZのバックアップ作成」を有効にすると、既存の `qgz` フォルダを作成日時付きの `qgz-YYYYMMDD-HHMMSS` へ変更してから、新しい `qgz` フォルダを作成します。
