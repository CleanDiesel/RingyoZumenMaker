# RingyoZumenMaker

QGISの測点レイヤから、林業向けの実測図・座標表・位置図を作成します。
QGIS 4.0以降、QGIS同梱Pythonとlxmlを使用します。

## 図面の分け方

入力は「基本情報」「施行地」「除地」「付帯工作物」「出力」に分かれます。

| 入力 | 作成する図面 |
|---|---|
| 施行地ポリゴンと除地ポリゴン・除地ライン | 全対象をまとめた実測図を1つ |
| 付帯工作物ライン | 登録したラインごとに実測図を1つ |

図面上部のタイトルはすべて「実測図」です。図面の選択欄では「施行地・除地」「付帯工作物 名称」で区別します。
座標表は24点ごとにページを分けます。同じ図面の座標表の続きでは地図を省略します。シェープファイルは作成しません。
付帯工作物だけの出力もできます。除地を指定する場合は施行地も必要です。

## 測点の指定

各区分の「追加」で対象を登録し、名前、ポイントレイヤ、抽出式、測点名、結合順を指定します。

```qgis
-- 選択した測点だけを対象にする
is_selected()

-- 属性で対象を絞り込む
"type" = '施行地'

-- 測点名
"name"

-- 結合順
"number"
```

ポリゴンは3点以上、ラインは2点以上必要です。測点名は複数登録でき、「主」の式を座標表に使います。
除地ラインは全幅を必須入力します（0.01m以上）。幅の有無を選ぶチェックボックスはありません。付帯工作物の幅は任意で、施行地からの差し引きには使いません。

## 属性・測量情報

施行地と付帯工作物で、測量日・測量事業者名・測量者名・製図日・製図事業者名・製図者名・林小班・山林所有者名を指定します。
振興局、市町村、事業コード、申請番号の入力欄はありません。

属性・測量情報はすべて直接入力します。ポイントレイヤの属性や式は参照しません。
施行地・除地の図面には共通の入力欄を1組設け、付帯工作物は登録ごとに独立した入力欄を設けています。
付帯工作物の入力欄は、それぞれの対象のタブ内にあります。他の図面や施行地とは連動しません。
製図事業者名・製図者名が空欄の場合は、同じ図面の測量事業者名・測量者名を使用します。
測点名・抽出条件・結合順には、引き続きポイントレイヤのフィールドや式を指定できます。

旧設定の共通の付帯工作物情報は、各図面へ固定値としてコピーして読み込みます。
旧「施行地から継承」は読み込み時に一度コピーし、以後は独立した値になります。
旧フィールド・式指定は実行せず、設定内に保存されていた固定入力値を使用します。

## 用紙・計算

基本情報は「座標系」「地図」「位置図」「計算・表示」のグループに分けています。
実測図はA4横・A3横に対応します。座標表と地図の比率を保って拡大します。
位置図は用紙（A4/A3）、縦・横、縮尺を実測図とは別に設定できます。
CRSは現場に合ったメートル単位の投影座標系を指定してください。

面積・延長は従来の測点計算を使います。

- 施行地面積は施行地ポリゴンの面積の合計です。
- 除地面積は除地ポリゴンの面積と除地ラインの「全幅×延長」の合計です。
- 最小除地面積は除地ラインごとに判定し、指定面積未満のラインを差し引きから除きます。単位はa（1a=100m²）です。
- 差引後の面積は施行地面積から除地面積を引いた値です。
- 除地同士の重複や施行地の外側の部分を自動処理する方式ではありません。入力の重複・範囲を確認してください。
- 付帯工作物の延長は施行地・除地の計算に含めません。

「試算」は計算結果の確認のみで、ファイルを作成しません。

## 出力・編集

既存の出力フォルダを選び「実行」を押します。

| 出力 | 内容 |
|---|---|
| `index.html` | 実測図・座標表。ブラウザで表示・印刷 |
| `asset/` | 図面の地図画像、表示に必要なファイル |
| `qgz/林小班.qgz` | 全図面のレイアウト・地図テーマをまとめた編集用QGZ。林小班が空欄なら`実測図.qgz` |
| `qgz/ringyo_zumen.gpkg` | 入力測点と図面用の点・線データ |
| `qgz/操作説明.md` | 編集方法と今回の出力先一覧 |
| `林小班 - 位置図.pdf` | 位置図を有効にした場合 |
| `input.config` | 実行時に自動保存する入力設定 |

「QGZの作成」を「作成しない」にすると、図面・位置図・設定を出力し、既存の`qgz`内のファイルを変更しません。
この場合は現在の入力設定から作り直し、QGZの手動編集は使いません。

処理前には`input.tmp.config`も保存します。正常終了時に削除し、エラー時は入力の復旧用に残します。
設定読み込みでこのファイルを指定することもできます。
従来のv1/v2設定は読み込み時に区分を変換します。旧「除地として扱う」は除地へ、その他のポリゴンは施行地、ラインは付帯工作物へ移します。

## 編集内容を引き継いで再作成する

生成した統合QGZを開くと、入力設定・測点レイヤが復元されます。
地図テーマで図面を選び、ラベルの移動、色や線、レイアウトを調整できます。
そのQGZを開いた状態で「作成する（QGZ・GPKG）」を選び再実行すると、同じ入力登録の編集内容を引き継いで計算し直します。
ラベル位置は測点の識別子で対応付けます。削除して再登録した対象は新しい図面として扱います。
基本情報の用紙や縮尺を変更した場合はその変更を優先し、同じ設定なら手動調整した縮尺を残します。

旧版の図面別QGZにはこの復元情報がないため、旧QGZの手動編集は自動移行しません。
旧成果品を残す場合は別の出力フォルダを指定してください。
詳しい操作は[図面の編集手順](qgs_editing.md)を参照してください。

## 印刷

`index.html`の「前の図面」「次の図面」または選択欄で図面を切り替えます。
「全図面を印刷」を選ぶと、全図面と座標表の続きもまとめて印刷します。
印刷設定は指定用紙、横向き、倍率100%、余白なし、ブラウザのヘッダー・フッターなしにしてください。「用紙に合わせる」などの自動拡大・縮小は使いません。
A4/A3とも地図画像の用紙上の寸法を固定し、QGZの再生成時も表示縮尺と印刷時の縮尺を一致させます。

## バックアップ

「生成ファイルのバックアップ」を有効にすると、生成履歴にある既存ファイルを`backup/日時/`へ退避します。
出力先に手動で追加したファイルは対象にしません。
無効の場合は生成ファイルを更新し、今回不要になった生成ファイルを除去します。
出力の確定に失敗した場合は、それまでのファイルを戻す処理を行います。
出力フォルダを移動するときはフォルダ全体を移動してください。外部背景データは参照元も必要です。

## プロセシング・バッチ実行

プラグインを読み込むと、プロセシングツールボックスの「RingyoZumenMaker」→「実測図」→「実測図を作成」が利用できます。
通常画面の「プロセシング」メニューからも開けます。

- 「バッチ処理…」でQGIS標準のバッチ画面を開きます。
- レイヤ・抽出条件・測点名・結合順・幅・測量情報・縮尺・出力先を、それぞれの列で指定できます。
- 各列のオートフィルで「下へコピー」や式による入力を使用できます。設定ファイルは必須ではありません。
- 出力フォルダは行ごとに分けてください。同じフォルダを指定すると生成ファイルの更新になります。
- 通常のプロセシング画面では、実行履歴やPythonコマンドのコピーなどQGIS標準の機能を利用できます。

ポイントレイヤは区分ごとに指定します。「区分の式」を空欄にすると抽出した全測点を1組として結びます。
同じレイヤに複数の施行地や工作物がある場合は、対象を分けるフィールド（例：`"区分"`）を指定します。
施行地・除地はまとめて1図面、付帯工作物は区分ごとに1図面になります。
図面情報は文字や日付を直接入力します。同じ行から生成する複数の付帯工作物には、その行の付帯工作物情報を使います。
図面ごとに情報を変える場合は、行を分け、抽出条件と出力フォルダをそれぞれ指定してください。
日付は`yyyy-MM-dd`形式です。

通常画面の「Pythonコマンドをコピー」「JSONとしてコピー」では、その画面の入力をコピーします。
各区分に1登録・測点名が1つの場合は、プロセシングの個別パラメータへそのまま対応付けます。
複数登録や複数の測点名がある場合は、全登録と図面ごとの情報を詳細入力として保持します。
この詳細入力があるときは出力フォルダ以外の個別パラメータより優先されます。
個別の列で編集する場合は、詳細設定の「通常画面の複数登録」を空にしてください。
メモリレイヤを参照するコマンドは、そのレイヤを開いているQGISセッションで実行します。

通常画面とプロセシングは、入力画面を作成しない共通の計算・図面出力処理を使います。
バッチ処理では現在のプロジェクトを閉じたり、出力QGZへ自動で切り替えたりしません。
位置図の背景は現在のプロジェクトの表示レイヤを使用します。
手動編集したQGZの編集内容を引き継いで更新するときは、そのQGZを開いて通常画面から実行してください。
